# Job Tracker

A full-stack job application tracking platform built with FastAPI, PostgreSQL, Next.js, and JWT authentication.

The application allows users to manage job applications, track interview progress, visualize analytics, and organize their job search through a secure dashboard interface.

---

## Features

- JWT Authentication
- Secure password hashing with bcrypt
- PostgreSQL database integration
- RESTful API architecture
- Job application CRUD operations
- Dashboard analytics
- Search and filtering
- Role-based access control (planned)
